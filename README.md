# Seattle Map Design  
[Access to Web map](http://127.0.0.1:5500/index.html)  

### Modified Basemap Layer  
I modified a classic monochrome basemap from Mapbox Studio styles to highlight important neighbourhoods and be aesthetically pleasing on the eye. I choses colours and label fonts to support the overlaying thematic data later used and unobstruct the geographic context (roads, water, landmarks). 

**Zoom levels:**
Zoom Z_3 – Z_12  
![Project Screenshot](assets/basemapscreenshot.png)  

### Thematic Historic Landmarks Map (with Basemap)  
The thematic layer includes a point for every historic landmark in Seattle. I chose purple for the point colour so that they would contrast with the base map, but still blend with the basemap colour theme. The data was obtained from Seattle's open source GeoData.  

**Zoom Levels**  
Zoom Z_3 - Z_12  
![Screenshot](assets/thematicscreenshot.png)  

### Thematic Historic Landmarks (no basemap)  
Each point represents different sites, buildings, vehicles, vessels, and street clocks that have been designated as Historic City Landmarks. The data is protected and updated daily by City Ordinance.  

**Zoom Levels**  
Zoom Z_3 - Z_12  
![Screenshot](assets/landmarksnobase.png)  

### Drainage Themed Map
The drainage themed map shows all drainage basins across Seattle. I designed the map with blue themes and symbology to emphasize water infrastructure and hydrologic boundaries. The data was collected from Seattle's opensource GeoData but it was originally provided by Seattle Public Utilities.  

**Zoom Levels**  
Zoom Z_3 - Z_12
